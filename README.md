# 🤖 Armando Group Manager — آرماندو

<div align="center">

**استفاده از این بات کاملاً رایگان است ❤️**

</div>

ربات مدیریت گروه تلگرام، **فارسی‌محور**، ماژولار و آمادهٔ استقرار (Railway).

ساخته‌شده با **Python 3.12+** و **aiogram 3.31** — کد کاملاً اورجینال، بدون کپی از ربات‌های موجود.

> همهٔ متن‌های ربات (دکمه‌ها، پیام‌ها، خطاها، راهنما، پنل، آمار) **فارسی** است.

---

## شیوهٔ تشخیص دستورات

ربات فقط زمانی واکنش نشان می‌دهد که پیام **خودِ دستور** باشد:

<div align="center">

| پیام | نتیجه |
|:---:|:---:|
| `قیمت دلار` | ✅ اجرا می‌شود |
| `قیمت دلار چقدر گرون شده` | ❌ گفتگوی عادی — واکنش نشان نمی‌دهد |
| `بن ۲روز تبلیغ` | ✅ اجرا می‌شود |
| `بن کردن این کار لازمه` | ❌ گفتگوی عادی |

</div>

دستوراتی که آرگومان نمی‌گیرند (`تاریخ`، `ارز دیجیتال`، `پنل` …) باید **دقیقاً همان عبارت** باشند.

| 🧹 **پاکسازی** | `پاکسازی ۱۰۰`، پاکسازی با محدوده، پاک‌سازی پیام‌های سرویسی، پین/آن‌پین و لیست پین‌ها |

| 📝 **فیلتر و یادداشت** | فیلتر با حالت‌های کلمه/عبارت/الگو/ریجکس، یادداشت با دکمه شیشه‌ای، دستورات شخصی، استیکر/گیف جادویی |

| 👋 **خوش‌آمد** | متن خوش‌آمد/خداحافظی با متغیرها (`{نام}`، `{کاربری}`، `{ایدی}`، `{تعداد}` …)، دکمهٔ شیشه‌ای، حذف خودکار |
